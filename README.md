### Selected work

**01 · [SHPE Connect](https://shpe-connect.vercel.app/)**

A full-stack platform for Texas A&M SHPE members that brings profiles, member discovery, career opportunities, and sponsor information into one place. Built with authentication, role-based access control, and targeted opportunity notifications.

<sub>`Next.js` · `TypeScript` · `PostgreSQL` · `Prisma` · `Better Auth` · `Tailwind CSS`</sub>

**02 · [Terminal Home](https://github.com/PabloAlmanza47/Terminal-Home)**

A keyboard-driven workspace manager for Linux and WSL. It discovers projects, creates configurable tmux environments, and resumes running sessions or rebuilds saved layouts, locally and over SSH. Tested with pytest, linted with Ruff, and type-checked with mypy in GitHub Actions.

<sub>`Python` · `Textual` · `tmux` · `pytest` · `GitHub Actions`</sub>
